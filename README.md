# 🏫 NIT Welcome Greeting Screen

A professional full-screen greeting display designed for Smart TVs, LED screens, and large displays used in colleges, offices, and reception areas.

---

## ✨ Features

- ⏰ Real-time clock (12-hour format with AM/PM)
- 🌞 Automatic greeting (Good Morning / Afternoon / Evening)
- 📅 Correct date and day display
- 🖼 Random image slideshow with smooth fade animation
- 📺 Optimized for Smart TVs and large screens
- 🌐 Works fully offline (no API dependency)
- 🧠 Smart image fit using CSS `object-fit`
- 🎓 Courses offered section
- 🏫 Campus events showcase
- 🔄 Auto refresh for long-running displays

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Responsive Grid & Flexbox)
- Vanilla JavaScript
